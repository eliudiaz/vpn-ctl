================================================================================
TROUBLESHOOTING
================================================================================

ISSUE: PING Timeout
  Possible causes:
    1. VPN tunnel not UP
    2. Firewall rules not configured at legacy network
    3. Routing table incomplete
  Solution:
    • Check: aws ec2 describe-vpn-connections (Tunnel 1 = UP?)
    • Check: aws ec2 search-transit-gateway-routes (routes active?)
    • Contact legacy network team - firewall may need to allow ICMP

ISSUE: Port 1433 Timeout
  Possible causes:
    1. MSSQL not running on legacy server
    2. Port 1433 blocked by firewall
    3. MSSQL TCP/IP not enabled
  Solution:
    • Confirm MSSQL running on 192.168.100.x:1433
    • Check firewall allows TCP/1433 from pod CIDR (172.31.0.0/16)
    • Enable TCP/IP protocol in MSSQL Configuration Manager

ISSUE: MSSQL Authentication Failed (Login Error)
  Possible causes:
    1. Wrong username or password
    2. MSSQL uses Windows authentication (not SQL auth)
    3. User account disabled or locked
  Solution:
    • Verify credentials: export MSSQL_USER=yourusername MSSQL_PASS=yourpass
    • Check if server uses Windows Auth (requires Kerberos setup)
    • Confirm sa user enabled and password correct
    • Try different MSSQL user account

ISSUE: CloudWatch shows REJECT actions
  Possible causes:
    1. Security group rules blocking traffic
    2. Network ACLs blocking traffic
  Solution:
    • Verify no AWS security groups blocking ICMP/TCP
    • Check VPC Network ACLs allow traffic
    • Confirm routes pointing to correct targets
