🎯 How to Use This Documentation

For Affinity DevOps Teams

Initial Setup: 1. Read: DEVOPS_QUICK_START.html (5 min) 2. Read: VPN_E2E_TESTING_PROTOCOL.html Phases 0-1 (15 min) 3. Execute Phase 0: Pulumi deployment 4. Create handoff: VPN_HANDOFF_TEMPLATE.html (10 min)

Phase 1 (Receiving): 1. Read: DEVOPS_QUICK_START.html (5 min) 2. Receive handoff package from Affinity

Phase 2 (Configuration): 3. Select device guide: CHECKPOINT_SETUP_GUIDE.html (or your device) 4. Follow Sections 1-6: Setup procedures (30-45 min) 5. Follow Section 8 (new): Joint E2E Testing (Phases 3-7)

Phase 3-7 (Testing): 6. Reference: VPN_E2E_TESTING_PROTOCOL.html for each phase 7. Run device-specific commands from your setup guide 8. Coordinate with Affinity at each gate

🛠️ Automation Tools

skill-vpn-e2e-test (Executable Script)

Location: aff-atg/skill-vpn-e2e-test

What it does: - Automated 5-layer testing: Reachability → IKE → IPSec → BGP → Traffic - Scoring system (0-100%) - Device-agnostic (runs from Affinity side) - Cloud Watch metrics integration

Usage:

# Quick check all peers
./skill-vpn-e2e-test

# Full E2E test for specific peer
./skill-vpn-e2e-test --peer Vimenca --e2e

# Layer-specific testing
./skill-vpn-e2e-test --peer Vimenca --layer 3    # BGP only
./skill-vpn-e2e-test --peer Checkpoint-DR --e2e

# Help
./skill-vpn-e2e-test --help

Output: - ✓ = Test passed - ✗ = Test failed (requires action) - ⚠ = Warning - Final score and recommendations

skill-vpn-connectivity (Enhanced)

Location: aff-atg/skill-vpn-connectivity

New features: - --e2e flag for E2E readiness checks - Integration with skill-vpn-e2e-test - –peer flag for specific peer monitoring - –analyze flag for health assessment

Usage:

# Quick status
./skill-vpn-connectivity

# Deep analysis
./skill-vpn-connectivity --deep

# E2E readiness
./skill-vpn-connectivity --e2e Vimenca

# Specific peer
./skill-vpn-connectivity --peer CIBA
